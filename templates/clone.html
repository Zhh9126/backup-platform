克隆前置条件（目标端需要什么）

克隆 = 把备份产物真实导入到目标实例并自动命名隔离（clone_N）。导入动作在目标端执行，因此目标端必须具备下表所列条件；提交前请先点「克隆预检」逐项核对。

源库类型目标主机怎么选目标端需要具备
Oracle选数据库服务器（如 192.168.163.195）服务器已纳管 SSH，impdp 由平台自动解析（服务器零安装）
Oracle平台本机 127.0.0.1平台侧安装 Oracle Instant Client（impdp/imp/sqlplus）+ 本机有 Oracle 实例承载 CLONE_N schema
MySQL / MariaDB任选目标实例端口可达、账号有建库权限；平台侧零安装（走 SSH 或本机客户端）
PostgreSQL / Kingbase / openGauss任选目标实例端口可达；平台侧 psql/pg_restore（金仓 ksql）或目标机自动解析
达梦 DM8任选同实例独立 schema 克隆（dimp 或 dmPython 通道）
常见失败「imp 客户端不可用 / impdp 客户端不可用」= 目标主机选了平台本机，但平台侧没有 Oracle 客户端：把目标主机改成数据库服务器即可，或在平台侧装 Instant Client 并配置工具路径。
数据库克隆能力

克隆采用异名数据库、schema 或 collection 隔离。恢复和校验依赖目标实例及原生工具。网络隔离、Live Mount 需专门的执行环境。

克隆件详情
立即克隆
选「应急接管」时，就绪后可做接管就绪检查（直连 / 表数量 / 行数抽样）。
高级选项
克隆库拉起位置。Oracle 建议直接填数据库服务器（走 SSH 用服务器自带 impdp，平台零安装）；填本机则平台侧需有 Oracle 客户端与本地实例。
整实例备份按库逐个恢复为 clone_N__原库名；库多时建议只填需要的库。
提交前可先做只读预检：源产物 / 目标端口 / 磁盘余量 / 凭据 / 安全隔离态（不创建申请、不拉起 VDB）。
VDB 快照管理
快照 = VDB 的时间点副本（含 sha256 对账）；「标准备份产物」由数据库自带工具生成，含表结构与一致性快照。
