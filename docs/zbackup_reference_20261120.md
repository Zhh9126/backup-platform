## 恢复验证

恢复校验页新增“部分通过”卡片及证据级别；报告导出分开统计三态。

- 文件、SHA256、格式检查或 prepare 工具检查成功，尚无隔离恢复副本查询证据：partial / artifact。
- 同一 source_record_id 的就绪测试、开发或预发布副本，通过当前查询验证：success / runtime。
- 文件损坏、引擎检查失败，或显式指定的隔离副本验证失败：failed。
- 自动查找副本时若不存在、过期或查询失败，仍只记录部分通过，不冒充实启通过。
- 禁止用生产库同名目标、在线模板/schema/快照克隆、DEMO 实例或其他备份的副本证明本次备份可恢复。
- Chroma 当前仅心跳可达不等于数据查询通过，仍记部分通过。
- 兼容 verify_record(record) 和 verify_record(record, options=...) 两种引擎签名。
- 历史 success 报告缺少证据级别时迁移为 partial / legacy_unverified；不删除报告。
- 每次策略执行使用独立 owner 的可续租操作锁，避免定时任务与手工执行重复进入。
- AI 自治复检修正策略创建与执行接口调用，复用相同的证据口径。

策略校验不会自行创建、接管或销毁数据库实例；使用已有克隆服务创建隔离副本，再校验。原有“克隆保留”字段没有因此获得新的自动清理语义，不能据此推断实例已经回收。

## 异地复制、取回及独立导入

池复制默认执行“上传数据 → 回读校验 → 上传清单 → 回读清单校验”，全部完成才记为 verified。清单包含原始备份时间、库型、备份方式、大小、SHA256 和对象键，不包含数据库密码或存储凭据。

- 同一链、同一记录的执行使用可续租操作锁。
- 扇出并发最多 8 个；每次复制默认生成独立对象键，防止同秒覆盖。
- 复用可取消指数退避；摘要不一致等确定性错误不盲目重试。
- 取回写同目录唯一临时文件，校验大小、摘要及清单关联后替换目标；失败保留原目标。
- 历史未经校验的日志不计入已验证副本数；历史取回必须有可信的记录摘要。
- 删除复制链后，副本记录继续可见、可取回。删除原站点目录不会自动删除目标副本。
- 每个目标对象的校验只证明该副本内容完整，不证明整个应用容灾或真实异地站点可接管。
- 回读验证增加一次完整数据读取，需要预留临时磁盘空间并评估实际网络成本。

### 灾备端操作步骤

1. 在“存储管理”配置能够访问副本数据的存储目标。
2. 在本平台建立对应的备份任务，数据库类型和备份方式须与副本一致。凭据继续由本平台任务管理。
3. 点击“从副本清单导入”，选择存储目标和任务，填写以 .aidbm-replica.json 结尾的清单对象键；建议填写从原站点另行保管的 SHA256。
4. 平台校验后生成备份记录，可进入既有恢复或克隆流程。重复导入相同已登记内容不会重复建记录。
5. 当前只允许完整 full/snapshot 副本独立导入；incremental/differential/log 不单独伪装成完整恢复链。

原站点“副本分布”会显示清单对象键，也可从存储目标上查找对应清单。导入不要求原站点记录 ID 或复制链仍然存在，源站点 ID 不会被直接当成本平台外键。

导入保留清单中的原备份时间，不用导入时间伪造较新的 RPO。导入的 verified 表示文件摘要一致，runtime_verified 仍为 false。内容哈希不等于清单签名；需要对抗存储内容整体篡改时，应保管独立可信摘要并采用不可变存储。

新增 API：
POST /api/pool/import
参数：target_id、manifest_key、task_id、expected_checksum（可选）。

## PITR

- 目标时间归一到元数据库本地时区；UTC/Z 输入与本地时间可正确比较，无效时间拒绝。
- “恢复到最新”按最新捕获点计算，不再把当前墙钟时间当成已有日志覆盖时间。
- 检查全量基线到第一日志段的衔接、binlog 文件序号跳跃和起始位置、WAL LSN 格式及缺口。
- 预览和实际执行共用结构连续性检查；执行额外核对本地产物和 SHA256。
- 显式目标超出已封存日志覆盖范围时，计划 complete=false。
- force 尽力恢复即使命令返回 0，也不报告已完整恢复到目标时间点。
- 时间轴显示 coverage_segments / coverage_gaps；扫描上限 10000，超出会显示截断说明。

重要边界：区间来自恢复点元数据和封存时间，不是对每种数据库原生事务日志内部时间的统一扫描。未知位点元数据、外部对象可达性和数据库实际回放仍需执行阶段与真实环境验证。未将所有数据库扩充为同一套已验证 PITR 引擎。
