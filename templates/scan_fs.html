特殊恢复
常规恢复不可用时的最后手段：只读扫描目标主机，把残留的原始数据文件 / 日志 / 控制文件拉回平台，交由人工或既有工具装载；已覆盖 Oracle、MySQL / MariaDB、PostgreSQL、金仓、openGauss、达梦、SQL Server、Redis、MongoDB、SQLite。
这是「特殊恢复」，不属于常规恢复链路
能做
  • SSH 只读扫描（lsblk / blkid / find / ps / oratab），零安装、零 agent
  • 按库型识别残留的数据文件、WAL / redo / binlog、控制文件与配置文件
  • 列出本机运行中的数据库实例（含数据目录与端口），进程已退出时按常见目录兜底
  • 勾选后经 SFTP 拉回平台并逐文件计算 sha256（可核对完整性）
不能做
  • 不读裸块设备、不做扇区级数据雕刻，已覆盖的块无法找回
  • 不自动修复数据库一致性：需按库型各自前滚 — Oracle 用 RMAN、MySQL 用 redo/binlog、PG / 金仓 / openGauss 用 WAL 回放、达梦用 dmrman、SQL Server 用事务日志、Redis 直接替换 RDB / AOF
  • 不会在目标主机写入或删除任何东西（只有「拉回」动作会落平台侧）
