# AIDBM 前端设计约束（v1）

日期：2026-09-23 ｜ 参考基准：Atlassian Confluence PRD 模板页信息架构
（https://www.atlassian.com/software/confluence/templates/product-requirements）
｜ 色彩基准：`static/css/app.css` 的 UI_DESIGN_SPEC（Slate + Teal）Tokens

> 定位：本文件是 AIDBM 全部页面的**唯一视觉与信息架构标准**。新增/改造页面
> 必须遵守；与页面内联样式冲突时，以本文件 + app.css Tokens 为准。

## 1. 设计原则（吸收 Atlassian 信息架构四条）

| # | 原则 | 落地要求 |
|---|---|---|
| P1 | **结论前置** | 每个列表页首屏必须回答"现在健康吗"：页标题下提供 KPI 摘要行（总数/启用/最近成功/最近失败），不让用户扫表格找答案 |
| P2 | **语义色统一** | 绿=成功、teal=运行中/进行、amber=警告、red=失败、slate=中性/停用。全站只用 app.css Tokens 的语义色，禁止页面自造颜色（无蓝紫渐变、无 Ant 蓝、无霓虹） |
| P3 | **操作降噪** | 行内操作用幽灵按钮（`.btn-row`：默认中性、危险操作悬停才显红）；一页只有一个主按钮（`.btn-primary`）；次要工具按钮统一 `.btn-outline-secondary` |
| P4 | **状态可追溯** | 失败状态必须可一键到达日志（记录行"日志"按钮 / 任务行失败徽章可点）；每条数据具备"查看—执行—追溯"闭环 |

## 2. 布局规格

### 2.1 页头区（每页固定三段）

```
[页标题 H1 22px/600]                    [主操作 btn-primary] [次要操作组 outline-secondary sm]
[副标题 13px muted]                     （主操作唯一强调，右侧对齐）
[KPI 摘要行 page-kpi（可选，列表页必带）]
```

- 标题 ≤ 3 级：页标题 → 卡片/区块标题 → 表头；
- KPI 摘要行：`.page-kpi`，分隔线分项，数字 600 加粗，失败项红色；
- 次要按钮（刷新/导入/模板等）一律中性描边，**不得**使用彩色 outline（warning/success/info）。

### 2.2 表格（`.page-card` 内 `.table`）

- 表头：12px/600、`#F8FAFC` 底、灰字（`--text-secondary`）、字距 .02em；
- 单元格：12px 14px 内边距、垂直居中；
- 悬停：`#F8FAFC`（不用 teal 染色，避免与选中态混淆）；
- IP/路径/哈希一律 `<code>`（12px 灰）；
- 列内容 > 1 行信息时拆列或收进悬停 title，禁止单元格内混排两种语义（如"每天 02:00 触发 / 手动"应拆主次）；
- 空状态：`.empty-state`（图标 + 一句标题 + 一句引导动作），禁止光秃秃"暂无数据"。

### 2.3 状态徽章（`.badge-ok / .badge-run / .badge-fail / .badge-sim`）

- 统一 pill 形态：999px 圆角、8% 语义色底、**前置圆点**（currentColor）；
- 运行中/进行态圆点带呼吸动画（`kpi-pulse`）；
- 全站（任务/记录/同步/迁移/克隆/实时）共用同一套类名，**禁止**每页自定义配色。

### 2.4 行内操作（`.btn-row`）

- 幽灵样式：无边框、灰字、悬停浅底；
- 主操作（如"立即备份"）`.btn-row-primary`（teal 加粗）；
- 危险操作（删除）`.btn-row-danger`：默认与普通操作同灰，**悬停才显红**——防止一屏多红；
- 图标 13px + 文字 13px；操作 ≤ 3 个平铺，更多收进「···」。

### 2.5 按钮

- 一屏只有一个 `.btn-primary`（页面主任务）；
- 次要操作 `.btn-outline-secondary`；确认/破坏性操作才用 danger；
- 按钮 `:active` 下沉 1px（已有），悬停禁止位移。

## 3. 禁止项（审查清单）

- ❌ 彩色描边按钮堆排（outline-warning/success/info 混用）
- ❌ 表格内多行彩色实心徽章并排（语义色超过一种即失败）
- ❌ 纯文本空状态（"暂无数据"四个字）
- ❌ 单元格内混排多种语义信息
- ❌ 页面内联 style 定义颜色/圆角（必须引用 Tokens）
- ❌ 违规色：蓝紫渐变 / Ant 蓝 #1677FF / 霓虹色 / 纯黑 #000
