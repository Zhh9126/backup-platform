# 实时备份、恢复与操作系统备份增强（2026-11-21）

## 实时数据库备份与恢复

- PITR 同一任务使用可续租操作租约 rt-pitr:<task_id>，防止两个恢复请求同时覆盖同一目标库或目录。
- 新增 /api/rt/integrity?task_id= 独立审计：检查恢复点同秒序号重复、产物缺失、SHA256 不匹配、恢复链完整性，并报告检查数量和截断状态。
- 实时恢复点原有跨进程事务序号分配、损坏段阻断后续发布和失败重试队列继续生效。
- 新增并发 PITR、恢复点篡改审计回归。

## 操作系统备份与恢复

- 新增 Agentless Linux 文件级 OS 备份：core/os_backup.py。
- 默认排除 /proc、/sys、/dev、/run、/tmp 等运行时目录，生成带 SHA256 文件清单的压缩归档。
- 新增操作系统备份记录表和 API：
  - GET /api/os-backup/records
  - POST /api/os-backup/backup
  - POST /api/os-backup/restore
- 恢复必须先预览校验，再显式 confirm=true；禁止归档路径穿越，恢复后重新计算每个文件 SHA256。
- 页面：/os-backup，支持备份、记录查看、恢复预览和独立目标目录恢复。
- 操作系统测试结果也进入统一 /test-records 页面。

## 测试和清理

- 本轮新增回归 11 项通过；结果已登记为测试记录 50。
- 本地 VM 测试的 6.5 GiB 热备归档和 6.6 GiB 冷备归档已清理，保留小型校验报告、日志、SQLite 验证结果和页面记录。
- 已清理后的 VM 归档不再提供网页下载；记录仍保留 SHA256、大小和验收结论，避免把已删除文件显示成可下载证据。

## 远程 OS 纳管

OS 备份页面现在支持选择已纳管 SSH 主机。远程流程为目标机原生 tar 归档、平台 SFTP 断点续传拉回、平台侧清单和 SHA256 校验、恢复前预览；目标机不安装 Agent。
本轮远程通道只做了模拟 SSH/SFTP 契约验证，尚无可用的第二台测试主机，因此未宣称真实跨主机传输验收；接入实际主机后应登记独立的外部实机测试记录。
