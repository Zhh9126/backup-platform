# 备份存储重删与网络重试改进（2026-11-20）

代码及验证均在 Linux /root/backup-platform-private 内完成。保留无 Agent 主通道和可选 Agent 通道，本次不需要在数据库主机安装软件。

## 存储与恢复

- FastCDC 流式切块，保留原算法边界；默认取消旧的 512 MiB 单文件入库限制。调用者仍可通过正数 max_bytes 设置上限。
- blob 和容器模式复用前解压并校验已有块 SHA-256；损坏块可在再次入库同内容时修复。清单记录实际块编码，兼容 zstd/zlib 切换。
- 同根目录使用线程锁与 Linux flock 协调入库、恢复、索引修改和 GC，避免清单发布前块被回收或多进程索引相互覆盖。
- 块、索引和清单使用唯一临时文件及原子替换，刷新文件和父目录。容器追加数据先 fsync 再发布索引。
- 恢复始终逐块校验长度和 SHA-256，即使关闭整体摘要校验也不跳过块校验；完整恢复成功后原子替换目标。失败保留已有目标。
- 清单结构、块指纹和容器路径校验；API 使用 commonpath 验证备份根目录。
- 清单损坏时 GC 停止删除；损坏容器索引拒绝更新。清单中的容器坐标可用于索引损坏后的恢复。
- GC 分开返回预计可回收与实际回收字节；定时任务对损坏清单明确告警。
- 全局固定块重删使用同一根目录的进程锁、原子落盘和内容校验，修复损坏块后不计复用节省。
- 全局统计改为 SUM(size_bytes * ref_count)，修复将所有块大小与总引用数相乘导致的节省量放大。
- 增量传输计划按目标清单计算缺失块字节，修复原先缺失块可能被算为零字节。
- 源端块去重组装经校验后原子发布；失败保留源端产物供重试，命中块也登记引用。原始备份产物仍保留，重删统计是块库口径，不表示已经释放原始备份占用。

## 网络传输

- 固定产物 SFTP 拉取采用任务 retry_max（额外重试次数，0 禁止重试，上限 100）和 retry_interval。
- 首次连接也进入重试范围；stat/read/rc 探测的网络错误向上透传，不再伪装为文件不存在、空文件或传输结束。
- 使用最高 300 秒的指数退避与 50%~100% 抖动；等待期间每 250 ms 检查取消。
- 不重试权限、路径、磁盘满、配额、只读文件系统等永久错误。
- SFTP 拉取和推送续传前流式校验整个已传前缀，错误残件重传；最终发布前再次比对完整内容。会增加校验读流量，低带宽环境需评估。
- 推送先传临时文件、校验本地源未改变和远端内容，再 POSIX 原子覆盖。扩展不支持时仅尝试标准 rename，不先删除已有目标。
- 对象下载不再仅凭残件大小等于期望大小就直接发布；本地永久资源错误立即退出，下载重试使用可取消退避。
- 不自动重新执行数据库备份命令，本次固定产物重试只重传既有产物。

- 相关回归：140 项通过，覆盖重删、块存储、容器、并发进程、恢复、传输、对象断点、源端去重及备份集成。
