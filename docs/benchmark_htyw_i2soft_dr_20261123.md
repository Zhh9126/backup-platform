## 2. AIDBM 当前容灾基线（代码事实）

- 切换引擎 `core/dr_failover.py`：MySQL 主从 detect → fence → promote → DNS 牵引（dnsmasq + 解析回读）→ 新主验证；GTID 分叉拦截、failback 追平、计划性两阶段切换。
- 编排与可观测：`core/dr_orchestrator.py`（预检/作业/取消/统计/总览）、`core/dr_monitor.py`（连续失败自动切换）、`core/dr_timeline.py`（五类事件 + 合规统计）、`core/dr_inspection.py`、`core/dr_compensation.py`（建议 + 可审批剧本）。
- 演练 `core/drill.py`：元数据级 / `real_restore`（MySQL 库级隔离）/ `switch` 三类，评分 100 分制、排程。
- 池复制 `core/pool_replication.py`：serial 级联 / parallel 扇出的**存储副本点位**链。
- 应用级 `core/dr_app_ha.py`：出站 HTTP 探活 + SQL/HTTP 断言，默认关闭，SSRF 拦截。

### 诚实边界（盘点确认）
1. 无 `sites` / `app_services` / `dr_switch_units` 表；`primary_site/dr_site` 仅 TEXT，`primary_region/dr_region` 只服务地图展示。
2. 单主单备，无候选备机池、无多级接管。
3. `rto_target_min/rpo_target_min` 只在 `protection_policies`；链路表无目标列；`slo_rto_sec` 只是事后统计，不驱动切换。
4. 默认演练是元数据级；`real_restore` 只支持 MySQL/MariaDB 同实例库级隔离；无即时挂载演练。
5. DNS 仅 dnsmasq；无云 DNS、VIP/LB 牵引；跨云复制未实现。
6. 切换仅 MySQL 引擎；取消信号重启丢失；补偿仅 DNS 一项可自动执行。
7. 应用级 HA 默认关闭，无业务服务实体/业务 IP 组。

## 3. 优化方案

### P0（本轮落地）

1. **站点与切换单元实体化（对标英方池化 + 航天云网节点）**
   - 新增 `dr_sites` 表：站点 id / 名称 / 地域（city/lat/lon）/ 角色（primary/standby/tertiary）/ 类型 / 优先级 / 启用。
   - 新增 `dr_failover_candidates`：链路的候选备机池（host/port/user/密码密文/priority/健康状态/启用），**按优先级多级接管**：第一个不具备条件（不可达/非复制角色/延迟超阈值）自动尝试下一个，逐步记录跳过原因。
   - 站点 CRUD API + 候选池 API + 前端管理面板。
2. **RTO/RPO 目标驱动（对标英方目标 + 航天云网 SLA）**
   - `disaster_links` 加 `rto_target_sec` / `rpo_target_min` 列。
   - 切换预检把"备机延迟 > RPO 目标"升级为风险项；切换结果把实测 RTO 与目标比对，输出 `slo_met` 与时间线合规统计；演练评分按目标扣分。
3. **容灾就绪度聚合（对标 i2DRM 统一视图）**
   - `GET /api/dr/readiness`：按链路给出站点健康、候选池可用数、目标对齐、最近演练/巡检/切换终态，只报真实探测结果。
4. **一致性真实校验增强**：链路 `check-consistency` 的 manual 模式明确 400（既有正确行为保留）；对绑定 sync/rt 源的链路，核对位点缺口并透出真实数值（不伪造 pass）。
5. **切换作业故障重调度**：与私有仓库持久队列对齐——平台重启后 `running` 超过租期的切换作业自动标记失败并告警，避免永久挂起（对应 PDF"节点故障任务重新调度"）。

### P1（明确本轮不做，列路线）

- 即时挂载演练（VDB COW 秒级多副本）：已有 VDB native 快照 + 回滚基础，需真机验证 COW 秒级复制后推进。
- 应用服务实体 + 业务 IP 组 + keepalived/VIP 牵引：需要现网应用服务器与网络条件。
- 非 MySQL 引擎切换（PG/金仓/达梦/Oracle）：需真机拓扑。
- 全局跨节点重删、自动扩容重平衡、跨云复制：结构性大件，与零 Agent/离线约束需重新评估。

### 不跟随（结构性不兼容或偏离定位）

- 航天云网"无上限集群 + PB 级分布式块存储"：AIDBM 是**备份管理平台**不是分布式存储，产品定位不同。
- 英方磁盘镜像级高可用（块级双机双柜）：与零 Agent、离线、数据库级恢复定位冲突。
- 双活/多活、读写分离：材料未披露具体承诺，且现网 DR 拓扑为主备，不做虚假支持。

1. **站点与候选池实体化**：`core/dr_topology.py`（懒建 `dr_sites` / `dr_failover_candidates`，`disaster_links` 迁移加 `rto_target_sec` / `rpo_target_min`）；`api/dr_topology.py` 12 个端点；`core/dr_orchestrator.precheck` 注入候选池摘要与目标风险。

4. **容灾就绪度聚合**：`GET /api/dr/readiness`（`?light=1` 跳过探测），只报真实探测结果，站点明确标注为配置实体。

### 本轮明确未做（如实）

- **自动多级接管**：候选备机可探测可排序，但"第一个不健康时自动换第二台执行切换"需动态替换 `FailoverEngine` 的 standby conn，涉及 fencing/DNS/GTID 一致性，风险高，列 P1；当前仅提供候选池展示 + 预检提示，由人工在切换向导中核对。
- 站点地图标注联动、即时挂载演练、应用服务实体/VIP、非 MySQL 切换、跨云复制：见第 3 节 P1/不跟随，均未在本次落地。
