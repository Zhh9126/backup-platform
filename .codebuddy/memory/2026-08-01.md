# 2026-08-01

## 插件系统重大重构

### 背景
用户明确需求：
1. 插件优先支持 Linux（后续部署到 Linux 服务器），Windows 不兼容也没关系
2. 数据库自带工具（RMAN、mysqldump、pg_dump、dmrman、sys_dump 等）不需要通过插件安装，备份时直接调用数据库路径下的可执行文件
3. 最终模式是离线安装——安装包预先下载好，部署时直接解压使用
4. `.download` 后缀导致下载后解压失败

### 修改内容

1. **修复 .download 后缀 bug**
   - 新增 `_guess_ext_from_url()` 从 URL 路径提取真实扩展名（.tar.gz / .zip 等）
   - `_download_and_extract()` 临时文件名使用真实扩展名，不再固定 .download

2. **删除不需要的 manifest（数据库自带工具）**
   - `oracle-rman-client.json` — RMAN 随 Oracle 自带
   - `dmrman.json` — dmrman 随达梦自带（$DM_HOME/bin/dmrman）
   - `kingbase-tools.json` — sys_dump/sys_basebackup/ksql 随金仓自带

3. **重写所有 7 个 manifest**
   - 全部移除 Windows 配置，只保留 `packages.linux`
   - 新增 `"offline_first": true` 标记
   - fallback URL 指向官方 tar.gz 下载（可直接解压使用）
   - 包管理器命令保留作为备选

4. **修改安装器优先级**
   - `_select_strategy()`: fallback_download > package_manager > manual_only
   - 原来：package_manager > fallback_download > manual_only

5. **增强 check_installed()**
   - 除了系统 PATH，还扫描安装状态文件中的 extract_dir/bin/ 路径
   - 状态文件新增 `plugin_id` 和 `extract_dir` 字段

6. **移除 Windows 包管理器支持**
   - `detect_package_manager()` 不再检测 choco/scoop
   - `detect_os()` 保留但仅用于显示提示

7. **前端适配**
   - plugins.html 副标题更新（明确哪些工具无需安装）
   - plugins.js 卡片 meta 显示"离线包"标签 + Linux 标签
   - 卸载确认框移除 choco 提及
   - 静态资源版本号更新为 v=2026080122
